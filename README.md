# Kidalovo

**Kidalovo** — это современная интерактивная доска для совместной работы в реальном времени. Проект позволяет пользователям создавать виртуальные пространства (комнаты), где можно обмениваться сообщениями, прикреплять файлы и рисовать на бесконечном холсте.

![Kidalovo Preview](https://picsum.photos/seed/kidalovo/1200/600)

## 🚀 Основные возможности

### 📋 Интерактивные сообщения
- **Карточки-стикеры**: Создавайте текстовые заметки, которые можно свободно перемещать и изменять в размере.
- **Поддержка файлов**: Прикрепляйте изображения и документы (интеграция с Cloudinary).
- **Форматирование**: Поддержка Markdown-подобной разметки (жирный, курсив, подчеркивание, зачеркивание, спойлеры и эмодзи).
- **Сворачивание**: Кликните по карточке, чтобы свернуть её и освободить место на холсте.

### 🎨 Векторное рисование
- **Инструменты**: Перо, стрелки, прямоугольники, эллипсы и треугольники.
- **Редактирование**: Выбирайте и перемещайте нарисованные объекты, вращайте их или изменяйте форму за узловые точки.
- **Синхронизация**: Все рисунки отображаются у всех участников комнаты мгновенно.

### 🔐 Приватность и Безопасность
- **Приватные комнаты**: Доступ по паролю.
- **Ограниченный доступ**: Режим "Только для авторизованных", закрывающий вход анонимным пользователям.
- **Список участников (Audit Log)**: В закрытых комнатах ведется список всех, кто когда-либо посещал доску.
- **Глобальная модерация**: Поддержка роли администратора для полного контроля над контентом.
- **Контент-фильтр**: Встроенная проверка сообщений на наличие нежелательного контента.

## 🛠 Технологический стек

- **Frontend**: [Next.js 14](https://nextjs.org/) (App Router), [TypeScript](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/), [Shadcn UI](https://ui.shadcn.com/)
- **Backend-as-a-Service**: [Firebase](https://firebase.google.com/) (Firestore для данных, Auth для авторизации)
- **Хранилище файлов**: [Cloudinary](https://cloudinary.com/)
- **Иконки**: [Lucide React](https://lucide.dev/)

## ⚙️ Настройка проекта

### 1. Клонирование репозитория
```bash
git clone https://github.com/your-username/kidalovo.git
cd kidalovo
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Переменные окружения
Создайте файл `.env.local` в корне проекта и добавьте следующие ключи:

**Firebase:**
Ключи можно получить в консоли Firebase (Project Settings).
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

**Cloudinary (для загрузки файлов):**
```env
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

### 4. Запуск в режиме разработки
```bash
npm run dev
```
Приложение будет доступно по адресу `http://localhost:9002`.

## 🌐 Развертывание (на Render.com)

1. Создайте **Web Service** на Render.
2. Подключите GitHub репозиторий.
3. Настройте команды:
   - **Build Command**: `npm run build`
   - **Start Command**: `npm start`
4. Добавьте все переменные окружения из шага 3 в разделе **Environment**.
