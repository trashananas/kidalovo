# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment)

Мы используем два сервиса: **Vercel** для основного хостинга и **Cloudflare Pages** в качестве прокси для обхода блокировок.

### Шаг 1: Развёртывание на Vercel

1.  Перейдите на сайт [Vercel](https://vercel.com/signup) и войдите, используя ваш аккаунт GitHub.
2.  В личном кабинете нажмите **"Add New... -> Project"**.
3.  Выберите ваш репозиторий `kidalovo` и нажмите **"Import"**.
4.  Раскройте секцию **"Environment Variables"**.
5.  Вставьте следующий текст целиком в поле **Key**. Vercel автоматически распознает и создаст три переменные. Замените значения на ваши ключи от Cloudinary, если они отличаются.

    ```
    NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=ВАШ_CLOUD_NAME
    CLOUDINARY_API_KEY=ВАШ_API_KEY
    CLOUDINARY_API_SECRET=ВАШ_API_SECRET
    ```

6.  Нажмите **"Deploy"**. Через несколько минут ваш сайт будет доступен по ссылке вида `https://kidalovo-*.vercel.app`. Убедитесь, что он работает, прежде чем переходить к следующему шагу.

### Шаг 2: Настройка прокси на Cloudflare Pages

Чтобы сайт был доступен в России, мы используем Cloudflare. Код в этом репозитории уже настроен для работы в качестве прокси.

1.  Перейдите на сайт [Cloudflare](https://dash.cloudflare.com/sign-up) и войдите.
2.  В меню слева выберите **Workers & Pages**.
3.  Нажмите **"Create application" -> "Pages" -> "Connect to Git"**.
4.  Выберите ваш репозиторий `kidalovo`.
5.  Нажмите **"Begin setup"**. В настройках сборки ничего менять не нужно, просто прокрутите вниз и нажмите **"Save and Deploy"**.

### Шаг 3: Используйте правильную ссылку

После завершения развертывания на Cloudflare, вы получите ссылку вида `https://kidalovo.pages.dev`.

**Используйте и делитесь только этой ссылкой (`https://kidalovo.pages.dev`).** Она будет работать везде, обходя блокировки.
