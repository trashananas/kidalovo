# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

Чтобы начать, взгляните на `src/app/page.tsx`.

## Развёртывание (Deployment)

Рекомендуемый и нативный способ хостинга для этого приложения — **Firebase App Hosting**. Это гарантирует полную совместимость со всеми функциями Firebase, которые мы используем.

### Как развернуть на Firebase App Hosting

Для развёртывания вам понадобится [Firebase CLI](https://firebase.google.com/docs/cli).

1.  **Установите Firebase CLI:** Если у вас его нет, установите его с помощью npm, выполнив в вашем терминале:
    ```bash
    npm install -g firebase-tools
    ```

2.  **Войдите в ваш аккаунт Google:**
    ```bash
    firebase login
    ```

3.  **Привяжите проект:** В корневой папке вашего проекта выполните команду, чтобы убедиться, что ваш локальный проект связан с вашим проектом Firebase:
    ```bash
    firebase use --add
    ```
    - В появившемся списке выберите ID вашего проекта Firebase (`studio-....`).

4.  **Разверните приложение:** После успешной привязки проекта выполните команду:
    ```bash
    firebase deploy --only apphosting
    ```

После завершения команды в терминале будет показана ссылка на ваше работающее приложение. Все последующие развёртывания выполняются той же командой `firebase deploy`. Этот метод намного надёжнее, и я уверен, что он сработает.
