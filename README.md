# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment)

Мы будем использовать **Firebase App Hosting**. Это современный, надёжный и бесплатный способ развернуть ваше приложение, который отлично работает в России и автоматически обновляется при изменениях в GitHub.

### Шаг 1: Добавление переменных окружения в Firebase

Как и в случае с Vercel, вашему приложению нужны ключи от Cloudinary для загрузки файлов.

1.  **Перейдите в консоль Google Cloud.** Это можно сделать по прямой ссылке: `https://console.cloud.google.com/run/secrets?project=studio-4983417966-5c3c2`
2.  Нажмите **"Создать секрет"** для каждой из трёх переменных:

    *   **Секрет 1:**
        *   **Имя секрета:** `cloudinary-api-key` (пишется строчными буквами)
        *   **Значение секрета:** Вставьте сюда ваш `CLOUDINARY_API_KEY` (например, `545999994157917`)
        *   Нажмите **"Создать секрет"**.

    *   **Секрет 2:**
        *   **Имя секрета:** `cloudinary-api-secret`
        *   **Значение секрета:** Вставьте сюда ваш `CLOUDINARY_API_SECRET`
        *   Нажмите **"Создать секрет"**.

    *   **Секрет 3:**
        *   **Имя секрета:** `next-public-cloudinary-cloud-name`
        *   **Значение секрета:** Вставьте сюда ваш `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` (например, `dtyamrurw`)
        *   Нажмите **"Создать секрет"**.

### Шаг 2: Подключение GitHub к Firebase App Hosting

1.  **Перейдите в Firebase App Hosting:** `https://console.firebase.google.com/project/studio-4983417966-5c3c2/hosting/backends`
2.  Нажмите **"Создать серверную часть" (Create backend)**.
3.  **Подключите GitHub.** Firebase попросит вас авторизоваться и выбрать репозиторий. Выберите ваш проект `kidalovo`.
4.  **Настройте развёртывание:**
    *   **Регион:** Выберите `us-central1` или любой другой.
    *   **Привяжите секреты:** На шаге "Привязка секретов" (Grant access to secrets) выберите все три секрета, которые вы создали (`cloudinary-api-key`, `cloudinary-api-secret`, `next-public-cloudinary-cloud-name`), и предоставьте им доступ.
5.  Нажмите **"Завершить и развернуть" (Finish and deploy)**.

Firebase автоматически начнёт сборку и развёртывание вашего проекта. Через несколько минут вы получите рабочую ссылку вида `https://[ВАШ-ID].firebaseapp.com` или `https://[ВАШ-ID].apphosting.dev`, которая будет доступна из любой точки мира.
