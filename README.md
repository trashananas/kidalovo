# Kidalovo — Интерактивная доска для совместной работы

**Kidalovo** — это современное веб-приложение для совместного творчества и обмена идеями в реальном времени. Проект позволяет пользователям создавать виртуальные пространства (комнаты), где можно обмениваться сообщениями, прикреплять файлы и рисовать на бесконечном холсте.

![Kidalovo Preview](https://picsum.photos/seed/kidalovo/1200/600)

## 🚀 Основные возможности

### 📋 Интерактивные сообщения
- **Карточки-стикеры**: Создавайте заметки, которые можно свободно перемещать, сворачивать или изменять в размере.
- **Форматирование (Markdown-like)**: Используйте спецсимволы для оформления текста (жирный `*`, курсив `\`, подчеркивание `_`, зачеркивание `$`, спойлер `#`).
- **Поддержка файлов**: Прикрепляйте изображения и документы (интеграция с Cloudinary).
- **Валидация контента**: Встроенная система проверки сообщений перед отправкой.

### 🎨 Векторное рисование
- **Инструменты**: Перо, стрелки, прямоугольники, эллипсы и треугольники.
- **Редактирование**: Выбирайте и перемещайте нарисованные объекты, вращайте их или изменяйте форму за узловые точки.
- **Real-time синхронизация**: Все изменения на холсте мгновенно отображаются у всех участников.

### 🔐 Приватность и Безопасность
- **Приватные комнаты**: Доступ по паролю для дополнительной защиты.
- **Закрытый режим**: Опция «Только для авторизованных», закрывающая вход анонимным пользователям.
- **Журнал участников (Audit Log)**: В закрытых комнатах ведется автоматический список всех пользователей, которые когда-либо заходили на доску.
- **Умное удаление**: Комнату может удалить создатель или последний оставшийся в ней участник.

## 🛠 Технологический стек

- **Frontend**: [Next.js 14](https://nextjs.org/) (App Router), [TypeScript](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/), [Shadcn UI](https://ui.shadcn.com/)
- **Backend**: [Firebase](https://firebase.google.com/) (Firestore для данных, Auth для авторизации)
- **Хранилище**: [Cloudinary](https://cloudinary.com/)
- **Иконки**: [Lucide React](https://lucide.dev/)

## ⚙️ Настройка и запуск

### 1. Установка зависимостей
```bash
npm install
```

### 2. Переменные окружения
Создайте файл `.env.local` в корне проекта и добавьте следующие ключи:

**Firebase:**
```env
NEXT_PUBLIC_FIREBASE_API_KEY=your_api_key
NEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your_project.firebaseapp.com
NEXT_PUBLIC_FIREBASE_PROJECT_ID=your_project_id
NEXT_PUBLIC_FIREBASE_APP_ID=your_app_id
```

**Cloudinary:**
```env
NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=your_cloud_name
CLOUDINARY_API_KEY=your_api_key
CLOUDINARY_API_SECRET=your_api_secret
```

### 3. Запуск в режиме разработки
```bash
npm run dev
```
