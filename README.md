# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment)

Мы будем использовать связку из **Vercel** (для хостинга приложения) и **Cloudflare** (для обхода блокировок в России). Этот метод надёжен и полностью бесплатен.

### Шаг 1: Развёртывание на Vercel

**ВАЖНО: Перед развёртыванием добавьте переменные окружения!**

Для загрузки файлов приложению нужны ключи от сервиса Cloudinary. Без них ваше приложение на Vercel не запустится или будет работать с ошибками.

1.  Зайдите в ваш проект `kidalovo` на Vercel.
2.  Перейдите в раздел `Settings` -> `Environment Variables`.
3.  Добавьте следующие три переменные, используя ваши учётные данные Cloudinary:

| Имя переменной                       | Значение                                 |
| ------------------------------------ | ---------------------------------------- |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`  | Ваше "Cloud Name" из Cloudinary        |
| `CLOUDINARY_API_KEY`                 | Ваш "API Key" из Cloudinary            |
| `CLOUDINARY_API_SECRET`              | Ваш "API Secret" из Cloudinary         |

**После добавления переменных, запустите новое развёртывание (redeploy) в Vercel, чтобы они применились.**

Вы уже развернули приложение по адресу `https://kidalovo.vercel.app`. Убедитесь, что переменные добавлены и последняя сборка прошла успешно.

### Шаг 2: Автоматическое проксирование через Cloudflare

Чтобы обойти блокировки Vercel в России, мы используем Cloudflare в качестве прокси.

В проект добавлен специальный файл-функция по адресу `functions/[[path]].js`. Cloudflare Pages автоматически использует этот файл, чтобы перенаправлять все запросы с `kidalovo.pages.dev` на ваш рабочий сайт `kidalovo.vercel.app`.

**Ваши действия:**

1.  **Сделайте коммит и отправьте изменения** в ваш `main` репозиторий на GitHub.
2.  **Дождитесь окончания сборки на Cloudflare.** Cloudflare автоматически обнаружит новый файл функции и всё настроит.

После этого ваше приложение должно стать доступно по адресу `https://kidalovo.pages.dev` и будет работать везде, включая мобильные устройства в России. Все будущие обновления, которые вы будете отправлять в `main` ветку, будут автоматически обновляться на Vercel, и Cloudflare продолжит их отображать.
