# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment) с помощью Netlify

Мы будем использовать **Netlify**. Это отличная, бесплатная альтернатива Vercel, которая стабильно работает в России и автоматически обновляется при изменениях в GitHub, **не требуя привязки банковской карты**.

### Шаг 1: Регистрация и импорт проекта

1.  Перейдите на сайт [Netlify](https://app.netlify.com/signup) и войдите, используя ваш аккаунт GitHub.
2.  В личном кабинете нажмите на кнопку **"Add new site"** и в выпадающем меню выберите **"Import an existing project"**.
3.  Выберите **GitHub** в качестве провайдера.
4.  Найдите и выберите ваш репозиторий `kidalovo`.

### Шаг 2: Настройка переменных окружения

Вашему приложению нужны ключи от Cloudinary для загрузки файлов. Их нужно добавить в настройки сайта на Netlify.

1.  После импорта репозитория Netlify перенаправит вас на страницу настроек сборки. Прокрутите вниз до раздела **"Environment variables"** и нажмите **"Add environment variables"**.
2.  Нажмите **"Add a variable"** и создайте три переменные одну за другой:

    *   **Переменная 1:**
        *   **Key:** `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`
        *   **Value:** Вставьте сюда ваш Cloud Name (например, `dtyamrurw`)

    *   **Переменная 2:**
        *   **Key:** `CLOUDINARY_API_KEY`
        *   **Value:** Вставьте сюда ваш API Key (например, `545999994157917`)

    *   **Переменная 3:**
        *   **Key:** `CLOUDINARY_API_SECRET`
        *   **Value:** Вставьте сюда ваш API Secret

### Шаг 3: Развёртывание

1.  Убедитесь, что Netlify автоматически определил настройки сборки (Build command: `next build`, Publish directory: `.next`). Обычно он делает это правильно для Next.js проектов.
2.  Нажмите кнопку **"Deploy site"**.

Netlify начнёт сборку и развёртывание вашего проекта. Через несколько минут вы получите рабочую ссылку вида `https://[ИМЯ-ВАШЕГО-САЙТА].netlify.app`, которая будет доступна из любой точки мира. Все последующие коммиты в ветку `main` будут автоматически развёртываться.
