# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени.

## Архитектура развёртывания

Мы используем **Render.com** для хостинга. Это надёжный сервис, который стабильно работает в России, имеет бесплатный тариф и автоматически обновляет сайт после каждого коммита в `main`.

## Настройка на Render.com

### Шаг 1: Создание сервиса

1.  Зарегистрируйтесь или войдите в [Render.com](https://dashboard.render.com/).
2.  Нажмите кнопку **"New +"** и выберите **"Web Service"**.
3.  Подключите ваш GitHub-репозиторий. Выберите репозиторий `kidalovo`.
4.  Настройте сервис:
    *   **Name**: `kidalovo` (или любое другое имя).
    *   **Region**: `Frankfurt (EU Central)` (рекомендуется).
    *   **Branch**: `main`.
    *   **Build Command**: `npm run build`
    *   **Start Command**: `npm start`
    *   **Instance Type**: **Free**.

5.  Нажмите **"Create Web Service"**. Первоначальная сборка начнется, но она, скорее всего, завершится с ошибкой, потому что мы еще не добавили ключи. Это нормально.

### Шаг 2: Добавление ключей Cloudinary

1.  После создания сервиса перейдите в его **Dashboard** и откройте вкладку **"Environment"**.
2.  В секции **"Environment Variables"** нажмите **"Add Environment Variable"**.
3.  Вам нужно добавить три ключа. **ВНИМАНИЕ:** Render не поддерживает вставку всего блока сразу, поэтому их нужно добавить по одному.

| Key                               | Value                                |
| --------------------------------- | ------------------------------------ |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME` | `dtyamrurw`                          |
| `CLOUDINARY_API_KEY`              | `545999994157917`                    |
| `CLOUDINARY_API_SECRET`           | `QeJqAQpY97FP-fjHqrPBiki6ygs`        |

4.  После добавления всех трех ключей, перейдите во вкладку **"Events"** и нажмите **"Deploy latest commit"**, чтобы запустить новую сборку с учётом добавленных ключей.

После завершения этой сборки ваше приложение будет доступно по адресу вида `https://kidalovo.onrender.com` из любой точки мира, включая Россию.
