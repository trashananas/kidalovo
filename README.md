# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment)

Мы будем использовать связку из **Vercel** (для хостинга приложения) и **Cloudflare** (для обхода блокировок в России). Этот метод надёжен и полностью бесплатен.

### Шаг 1: Развёртывание на Vercel

1.  **Зарегистрируйтесь на Vercel:** Перейдите на [vercel.com](https://vercel.com/) и зарегистрируйтесь, используя ваш аккаунт GitHub.

2.  **Импортируйте проект:**
    *   После регистрации вас перенаправит на дашборд. Нажмите **"Add New... -> Project"**.
    *   Найдите в списке ваш репозиторий `kidalovo` и нажмите **"Import"**.

3.  **Настройте переменные окружения:**
    *   В настройках проекта найдите раздел **"Environment Variables"**.
    *   Вам нужно добавить **четыре** переменных, которые вы использовали для Cloudinary. Vercel требует, чтобы публичные переменные (которые доступны в браузере) имели префикс `NEXT_PUBLIC_`.

| Имя переменной (Name)                | Значение (Value)                     |
| ------------------------------------ | ------------------------------------ |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`  | `Ваше cloud name`                    |
| `NEXT_PUBLIC_CLOUDINARY_API_KEY`     | `Ваш API Key`                        |
| `CLOUDINARY_API_KEY`                 | `Снова тот же API Key`               |
| `CLOUDINARY_API_SECRET`              | `Ваш API Secret`                     |

    *   **Важно:** `NEXT_PUBLIC_CLOUDINARY_API_KEY` и `CLOUDINARY_API_KEY` — это две разные переменные с одинаковым значением.

4.  **Разверните проект:**
    *   Нажмите кнопку **"Deploy"**. Vercel автоматически всё соберёт и развернёт.
    *   Через пару минут вы получите рабочую ссылку (например, `kidalovo-xyz.vercel.app`). **Эта ссылка нам понадобится на следующем шаге.**

### Шаг 2: Настройка прокси в Cloudflare

Теперь мы "спрячем" ссылку Vercel за доменом Cloudflare, который не блокируется.

1.  **Зайдите в Cloudflare:** Откройте ваш [дашборд Cloudflare](https://dash.cloudflare.com/).

2.  **Перейдите в раздел Workers & Pages:** В меню слева выберите "Workers & Pages".

3.  **Выберите ваше приложение:** Найдите в списке `kidalovo` и нажмите на него.

4.  **Перейдите в настройки домена:** Внутри вашего проекта выберите вкладку **"Custom domains"**.

5.  **Настройте Custom Domain:**
    *   Нажмите кнопку **"Set up a domain"**.
    *   В поле введите основной домен, который вам выдал Cloudflare, когда вы создавали проект Pages. Обычно он выглядит как `kidalovo.pages.dev`. Нажмите **"Continue"**.
    *   Cloudflare покажет вам сообщение "Updating CNAME record...". Это нормально. Через минуту он должен написать "Active".

Поздравляем! Теперь ваше приложение доступно по ссылке `https://kidalovo.pages.dev` и должно работать в России на всех устройствах, так как весь трафик идёт через Cloudflare. Все последующие коммиты в `main` ветку будут автоматически обновлять сайт на Vercel, и Cloudflare будет подхватывать изменения.
