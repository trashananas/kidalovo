# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

Чтобы начать, взгляните на `src/app/page.tsx`.

## Развёртывание (Deployment)

Рекомендуемый способ хостинга для этого приложения — **Vercel**, платформа от создателей Next.js. У них есть надёжный бесплатный тариф.

### Как развернуть на Vercel

1.  **Зарегистрируйтесь на Vercel:** Перейдите на [vercel.com](https://vercel.com/) и зарегистрируйтесь, используя ваш аккаунт GitHub.

2.  **Импортируйте проект:**
    *   После регистрации вас перенаправит на дашборд. Нажмите **"Add New... -> Project"**.
    *   Найдите в списке ваш репозиторий `kidalovo` и нажмите **"Import"**.

3.  **Настройте переменные окружения:**
    *   В настройках проекта найдите раздел **"Environment Variables"**.
    *   Вам нужно добавить **четыре** переменных, которые вы использовали для Cloudinary. Vercel требует, чтобы публичные переменные (которые доступны в браузере) имели префикс `NEXT_PUBLIC_`.

| Имя переменной (Name)                | Значение (Value)                     |
| ------------------------------------ | ------------------------------------ |
| `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`  | `Ваше cloud name`                    |
| `NEXT_PUBLIC_CLOUDINARY_API_KEY`     | `Ваш API Key`                        |
| `CLOUDINARY_API_KEY`                 | `Снова тот же API Key`               |
| `CLOUDINARY_API_SECRET`              | `Ваш API Secret`                     |

    *   **Важно:** `NEXT_PUBLIC_CLOUDINARY_API_KEY` и `CLOUDINARY_API_KEY` — это две разные переменные с одинаковым значением.

4.  **Разверните проект:**
    *   Нажмите кнопку **"Deploy"**. Vercel автоматически всё соберёт и развернёт.
    *   Через пару минут вы получите рабочую ссылку на ваше приложение. Все последующие коммиты в `main` ветку будут автоматически обновлять сайт.
