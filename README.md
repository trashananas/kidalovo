# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени.

## Архитектура развёртывания

Проект использует гибридную схему для обеспечения доступности в России:
1.  **Vercel** (`kidalovo.vercel.app`) — основной хостинг, где работает само приложение. Он автоматически обновляется при коммитах в `main`.
2.  **Cloudflare Pages** (`kidalovo.pages.dev`) — прокси-сервер, который обеспечивает доступ к сайту из России, перенаправляя запросы на Vercel.

## Настройка

### Шаг 1: Настройка Vercel (Основной сайт)

1.  Подключите ваш GitHub-репозиторий к Vercel.
2.  Перейдите в настройки проекта (`Settings` -> `Environment Variables`).
3.  Добавьте три переменные окружения для работы с Cloudinary. Вы можете вставить весь блок ниже в поле `Key`, и Vercel распознает их автоматически:

    ```
    NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=dtyamrurw
    CLOUDINARY_API_KEY=545999994157917
    CLOUDINARY_API_SECRET=QeJqAQpY97FP-fjHqrPBiki6ygs
    ```
4.  Сохраните переменные. Vercel начнет новую сборку. Дождитесь ее завершения. После этого ваш основной сайт `https://kidalovo.vercel.app` должен работать.

### Шаг 2: Настройка Cloudflare Pages (Прокси)

1.  Подключите тот же GitHub-репозиторий к Cloudflare Pages.
2.  На шаге **"Set up builds and deployments"** ничего не меняйте. Просто нажмите **"Save and Deploy"**.
3.  Cloudflare развернет прокси-функцию, которая находится в файле `functions/[[path]].js`.

После завершения развертывания на Cloudflare, ваш сайт должен быть доступен по адресу **https://kidalovo.pages.dev** из любой точки мира, включая Россию.
