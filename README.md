# Kidalovo — Интерактивная доска для совместной работы

Интерактивное веб-приложение для совместного творчества в реальном времени.

## Возможности

- **Карточки-стикеры**: Создание, перемещение и изменение размера заметок.
- **Рисование**: Векторные инструменты (перо, фигуры, стрелки) с синхронизацией.
- **Приватность**: Доступ по паролю и режим «Только для авторизованных».
- **Аудит**: Автоматический список участников в закрытых комнатах.

## Технологии

- Next.js 14, TypeScript, Tailwind CSS
- Firebase (Firestore, Auth)
- Cloudinary

## Настройка

1. Установите зависимости: `npm install`
2. Создайте `.env.local` на основе `.env` и заполните ключи.
3. Запустите: `npm run dev`

Важно: файл `.env.local` не должен попадать в репозиторий.
