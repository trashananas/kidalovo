# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание на Render.com

Мы будем использовать **Render.com** — это бесплатный, надежный хостинг, который работает в России и автоматически обновляется вместе с вашим GitHub-репозиторием. Привязка банковской карты не требуется.

### Шаг 1: Регистрация на Render

1.  Перейдите на сайт [Render.com](https://dashboard.render.com/register) и войдите, используя ваш аккаунт GitHub.

### Шаг 2: Создание нового Web-сервиса

1.  В личном кабинете нажмите **"New + -> Web Service"**.
2.  В разделе "Public Git Repositories" вставьте ссылку на ваш GitHub-репозиторий: `https://github.com/ваше_имя/kidalovo` (замените `ваше_имя` на ваш логин GitHub). Нажмите **"Continue"**.
3.  На следующей странице заполните поля:
    *   **Name**: `kidalovo` (или любое другое имя)
    *   **Region**: `Frankfurt (EU Central)` (или любой другой)
    *   **Branch**: `main`
    *   **Runtime**: `Node`
    *   **Build Command**: `npm install && npm run build`
    *   **Start Command**: `npm start`
    *   **Instance Type**: `Free`

### Шаг 3: Добавление переменных окружения

1.  Прокрутите страницу вниз до секции **"Advanced"** и раскройте её.
2.  Нажмите **"Add Environment Variable"**.
3.  В поле **Key** вставьте весь блок текста ниже. Render автоматически распознает и создаст три переменные.

    ```
    NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=ВАШ_CLOUD_NAME
    CLOUDINARY_API_KEY=ВАШ_API_KEY
    CLOUDINARY_API_SECRET=ВАШ_API_SECRET
    ```
    **Важно:** Замените `ВАШ_CLOUD_NAME`, `ВАШ_API_KEY`, и `ВАШ_API_SECRET` на ваши реальные значения из Cloudinary.

### Шаг 4: Запуск развёртывания

1.  Прокрутите в самый низ страницы и нажмите кнопку **"Create Web Service"**.
2.  Render начнет сборку и развёртывание вашего приложения. Это займёт несколько минут.
3.  Как только сборка завершится, ваш сайт будет доступен по ссылке, указанной в верхней части страницы (вида `https://kidalovo.onrender.com`).

**Используйте и делитесь именно этой ссылкой. Она будет работать везде.**
