# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени.

## Развёртывание на Netlify (Рекомендуемый способ)

Netlify — это бесплатный хостинг, который стабильно работает в России, автоматически обновляется при изменениях в GitHub и не требует привязки банковской карты для бесплатного тарифа.

### Шаг 1: Регистрация и создание сайта

1.  Перейдите на сайт [Netlify](https://app.netlify.com/signup) и войдите, используя ваш аккаунт GitHub.
2.  После входа в личный кабинет нажмите **"Add new site"** и выберите **"Import an existing project"**.
3.  Нажмите на кнопку **"Deploy with GitHub"** и разрешите Netlify доступ к вашим репозиториям.
4.  Выберите ваш репозиторий `kidalovo`.

### Шаг 2: Настройка переменных окружения

1.  После выбора репозитория Netlify покажет вам настройки сборки. **Не нажимайте "Deploy" сразу!** Прокрутите страницу вниз до секции **"Advanced build settings"**.
2.  Нажмите **"New variable"**, чтобы добавить переменные окружения. Вам нужно добавить три ключа от Cloudinary.

    *   **Переменная 1:**
        *   **Key:** `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`
        *   **Value:** `ВАШ_CLOUD_NAME` (возьмите из вашего аккаунта Cloudinary)

    *   **Переменная 2:**
        *   **Key:** `CLOUDINARY_API_KEY`
        *   **Value:** `ВАШ_API_KEY`

    *   **Переменная 3:**
        *   **Key:** `CLOUDINARY_API_SECRET`
        *   **Value:** `ВАШ_API_SECRET`

### Шаг 3: Развёртывание

1.  Убедитесь, что основные настройки сборки (**Build settings**) определились автоматически:
    *   **Build command:** `next build`
    *   **Publish directory:** `.next`
2.  После добавления всех трёх переменных нажмите оранжевую кнопку **"Deploy `kidalovo`"**.

Через несколько минут ваш сайт будет готов и доступен по ссылке вида `https://название-вашего-сайта.netlify.app`. Эту ссылку можно безопасно использовать и делиться ей.
