# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment) на Render

Мы используем хостинг **Render**, так как он стабильно работает в России, имеет бесплатный тариф без привязки карты и автоматически обновляется при изменениях в GitHub.

### Шаг 1: Регистрация и создание сервиса

1.  Перейдите на сайт [Render](https://dashboard.render.com/register) и зарегистрируйтесь, используя ваш аккаунт GitHub.
2.  В личном кабинете нажмите **"New" -> "Web Service"**.
3.  Найдите в списке ваш репозиторий `kidalovo` и нажмите **"Connect"**.
4.  Заполните настройки сервиса:
    *   **Name**: `kidalovo` (или любое другое имя)
    *   **Region**: `Frankfurt (EU Central)` (рекомендуется)
    *   **Branch**: `main`
    *   **Runtime**: `Node`
    *   **Build Command**: `npm run build`
    *   **Start Command**: `npm start`
    *   **Instance Type**: `Free`

### Шаг 2: Добавление переменных окружения

1.  Прокрутите страницу создания сервиса вниз и откройте секцию **"Advanced"**.
2.  Нажмите **"Add Environment Variable"**.
3.  В поле **Key** вставьте весь блок текста ниже. Render автоматически распознает и создаст три переменные.

    ```
    NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=dtyamrurw
    CLOUDINARY_API_KEY=545999994157917
    CLOUDINARY_API_SECRET=QeJqAQpY97FP-fjHqrPBiki6ygs
    ```
    > **ВАЖНО:** Если вы копировали ключи из другого места, убедитесь, что они верны. Эти значения взяты из нашего предыдущего обсуждения.

### Шаг 3: Запуск

1.  Прокрутите в самый низ страницы и нажмите **"Create Web Service"**.
2.  Render начнёт сборку и развёртывание вашего приложения. Первый запуск может занять 5-10 минут.
3.  После завершения ваш сайт будет доступен по ссылке вида `https://kidalovo.onrender.com`.

**Используйте и делитесь только этой ссылкой.** Она будет работать у всех.
