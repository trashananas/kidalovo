# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени, созданной в Firebase Studio.

## Развёртывание (Deployment)

Мы используем сервис **Render** для хостинга. Он предоставляет бесплатный тариф, не требует банковской карты и стабильно работает в России.

### Шаг 1: Регистрация на Render

1.  Перейдите на сайт [Render](https://render.com/) и нажмите **"Get Started"** или **"Sign In"**.
2.  Выберите вариант регистрации с помощью вашего аккаунта **GitHub**.

### Шаг 2: Создание нового Web Service

1.  В личном кабинете нажмите **"New + -> Web Service"**.
2.  В секции **"Public Git repository"** вставьте ссылку на ваш GitHub репозиторий: `https://github.com/ВАШ_НИК/kidalovo` (замените `ВАШ_НИК` на ваш логин). Нажмите **"Continue"**.
3.  На следующем экране Render проанализирует ваш проект.

### Шаг 3: Настройка сервиса

Заполните поля следующим образом:

1.  **Name**: `kidalovo` (или любое другое имя).
2.  **Region**: Оставьте `Oregon (US West)` или выберите ближайший к вам.
3.  **Branch**: `main`.
4.  **Runtime**: `Node`.
5.  **Build Command**: `npm run build`
6.  **Start Command**: `npm start`
7.  **Instance Type**: `Free`.

### Шаг 4: Добавление переменных окружения

Это самый важный шаг.

1.  Прокрутите вниз до секции **"Environment"**.
2.  Нажмите **"Add Environment Variable"**.
3.  Вам нужно добавить три переменные с вашими ключами от Cloudinary. Нажимайте **"Add Environment Variable"** для каждой новой переменной.

    *   **Key**: `NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`, **Value**: `ВАШ_CLOUD_NAME`
    *   **Key**: `CLOUDINARY_API_KEY`, **Value**: `ВАШ_API_KEY`
    *   **Key**: `CLOUDINARY_API_SECRET`, **Value**: `ВАШ_API_SECRET`

    **Важно:** Убедитесь, что вы не перепутали `Key` (имя) и `Value` (значение).

### Шаг 5: Запуск развёртывания

1.  Прокрутите в самый низ страницы и нажмите **"Create Web Service"**.
2.  Render начнёт установку зависимостей и сборку проекта. Это может занять несколько минут. Вы можете наблюдать за процессом в логах.
3.  После успешной сборки ваш сайт будет доступен по ссылке вида `https://kidalovo.onrender.com`.

**Используйте и делитесь только этой `onrender.com` ссылкой.** Она будет работать везде. При каждом новом коммите в ветку `main` ваш сайт на Render будет автоматически обновляться.
