# Kidalovo

Это стартовый проект для приложения "Kidalovo" — доски для сообщений в реальном времени.

После многочисленных проблем с Vercel и сложными прокси, мы переходим на единственно верный и простой способ развёртывания.

## Финальный и единственно правильный способ развёртывания

Мы будем развёртывать приложение **напрямую на Cloudflare Pages**. Этот способ надёжен, работает в России без блокировок и не требует двух разных сервисов, что исключает все предыдущие ошибки.

### Шаг 1: Подключение проекта к Cloudflare

1.  Зайдите в ваш аккаунт [Cloudflare](https://dash.cloudflare.com/).
2.  В меню слева выберите **Workers & Pages**.
3.  Нажмите **"Create application"**, перейдите на вкладку **Pages** и нажмите **"Connect to Git"**.
4.  Выберите ваш GitHub-репозиторий `kidalovo`.
5.  На шаге **"Set up builds and deployments"** вам нужно сделать одну важную вещь.

### Шаг 2: Настройка сборки

1.  В поле **"Framework preset"** выберите из выпадающего списка **Next.js**. Cloudflare автоматически подставит правильные команды сборки.
2.  Больше ничего не меняйте на этом экране. Прокрутите вниз.

### Шаг 3: Добавление переменных окружения (Ключевой шаг!)

1.  На той же странице найдите секцию **"Environment variables"** и нажмите **"Add variable"**.
2.  Вам нужно добавить три переменные с вашими ключами от Cloudinary. **Это тот же самый процесс, что вы безуспешно пытались сделать в Vercel.**

    Вы можете скопировать этот блок, вставить его в поле **Variable name** и Cloudflare должен распознать все три:
    ```
    NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME=dtyamrurw
    CLOUDINARY_API_KEY=545999994157917
    CLOUDINARY_API_SECRET=QeJqAQpY97FP-fjHqrPBiki6ygs
    ```
4.  Убедитесь, что все три переменные (`NEXT_PUBLIC_CLOUDINARY_CLOUD_NAME`, `CLOUDINARY_API_KEY`, `CLOUDINARY_API_SECRET`) добавлены.
5.  Нажмите **"Save and Deploy"**.

### Шаг 4: Ожидание и проверка

1.  Cloudflare начнёт процесс сборки и развёртывания вашего сайта. Это может занять несколько минут.
2.  После завершения ваш сайт по ссылке **https://kidalovo.pages.dev** должен заработать полностью.

Это самый чистый и надёжный способ, который решит все наши проблемы.
