# **App Name**: LetterBoard

## Core Features:

- Room Creation: Allow a user to create a room and generate a unique 4-letter code for others to join.
- Room Joining: Enable users to join a room by entering the 4-letter code.
- Message Sending: Allow users to send text messages to the shared room.
- Message Display: Display messages as movable elements on a shared board instead of a traditional chat interface. Make a tool to classify if a new message adds information or contradicts what's on the board
- Realtime Updates: Ensure all connected users receive updates in real-time.

## Style Guidelines:

- Primary color: Yellowish hue (#FAF9F6) to create a warm and inviting environment for message exchange.
- Background color: White (#FFFFFF) to provide a clean and neutral backdrop that does not distract from the message board.
- Accent color: Pale Yellow (#FFFFE0), offering a subtle highlight for important interactive elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif, which is well-suited to on-screen reading given its clean, neutral, and objective appearance.
- Implement a drag-and-drop interface for moving messages around the board freely.
- Use simple, clear icons for key actions such as sending messages and room settings.
- Use subtle animations for message arrival and movement to provide feedback without being distracting.
